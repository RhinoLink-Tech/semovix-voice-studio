## Sev-2（可带条件发布，已有可靠规避方案）

### KI-1 授权真人克隆的正式发布与生产调用在 Alpha 中禁用

- **现象**：克隆来源完成授权归档、参考音频与来源验证后，`PUT/POST` 发布路由返回 409 `clone_publish_disabled_in_alpha`；消费侧返回 409 `clone_profile_disabled_in_alpha`。
- **根因**：授权到期/撤销的**运行时**策略检查尚未实现（归档时的静态校验存在）。为避免"缺运行时约束却正式发布"，按验收 §2.7 选项 2 在 Alpha 期禁用整条发布链（提交 `cd2fc5a`）。
- **规避**：授权材料归档、克隆样本试听等非发布功能可正常使用；需要正式克隆发布的场景请等待后续版本。
- **解除条件**：补齐运行时授权策略（含撤销态）后移除两道门。

### KI-2 手工删除库内批次目录会卡死同号新批次

- **现象**：手工删除 `library/voice-design-batches/<id>` 目录后，分配器会复用该编号；新建批次对 `submitJob` 呈现既有任务行而被**静默回放**（`server/jobs/runner.ts:119-120`），新批次永远停在 `queued`。
- **根因**：批次号唯一性假设依赖库目录不被外部修改；任务行回放未校验库内产物是否仍在。
- **规避**：**不要手工删除库内目录**；清理请走产品界面或后续提供的批次治理接口。当前库中 `20260930-01` 即为此状态的僵尸批次（不影响其他批次）。
- **计划**：后续版本提供批次清理/取消口径，并在 `submitJob` 回放前校验域文件存在性。

### KI-3 集成测试在真实 Worker 同机运行时偶发失败

- **现象**：全量 `bun run test` 期间若本机 8800 端口有真实 Worker，偶发 1 例集成测试失败（不同文件、低概率；2026-09-30 观测 6/8 次运行→随后 11+ 连续通过）。
- **根因**：疑似残留的 undici 直连路径绕过 fetch 桩触达真实 Worker（与 `f0a7c54` 修复的失败同族），未根因。
- **规避**：运行发布级测试前停止本机 dev stacks（API/Worker），或重跑一次以区分 flake 与真实回归。

## Sev-3（顺延到后续版本）

### KI-4 `GET /validation-run` API 响应不含 `modelIdentity`

库内 `validation-run.json` 与 Profile Manifest 均完整记录推理时刻模型身份；仅 API 序列化视图缺该字段。不影响正确性与溯源，需要 API 侧可观测时再补。

### KI-5 响度处理无 BS.1770 / EBU R128 闭环

多轨混音执行 EQ、压缩、峰值归一与人声优先 Auto Ducking，但**没有** LUFS 响度测量闭环，不能用于证明达到任何平台响度标准（PR-1 已在 UI 与文档统一口径，此处存档为已知限制）。

## 设计性限制（非缺陷，发布口径的一部分）

- **单机/受控内网定位**：无内置身份认证、多租户与审计汇聚；多用户部署需按 [docs/DELIVERY.md](docs/DELIVERY.md) 由基础设施补齐。
- **模型权重不随仓库分发**：首次运行按需下载（Base/VoiceDesign 各 ≈4.2G，whisper-large-v3-turbo ≈1.5G）；同名权重更新后不保证严格复现历史输出（推理时刻模型身份记录入 Manifest）。
- **跨平台现状**：真实模型验收仅在单台 Apple Silicon macOS 开发机完成；Windows 安装包未构建、未验收。
- **CI 边界**：CI 使用伪模型，覆盖路由/状态机/幂等/Hash/文件安全/任务恢复，不证明音质与跨平台可用性。
